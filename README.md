# NusaEco
NUSA ECO adalah platform digital edukasi dan pengelolaan sampah berbasis sekolah yang dirancang untuk mendukung gerakan peduli lingkungan melalui Bank Sampah, Scan Sampah, Dashboard, dan Eco Impact. Mengajak siswa membangun kebiasaan memilah dan mengelola sampah demi lingkungan sekolah yang lebih bersih dan berkelanjutan. Small Waste, Big Change.
